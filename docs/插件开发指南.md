# iread 插件开发指南

> 适用对象：想给 iread 加功能、又不改主程序的开发者。
> 适用版本：**iread 插件测试版**（ **没有**插件运行时）。
> 位置：程序 `iread-plugin.exe`，安装目录 `%LOCALAPPDATA%\iread-plugin`，数据目录 `%LOCALAPPDATA%\iread-plugin-data`。

---

## 1. 插件能做什么、不能做什么

**能做**（v1 开放的能力）：

| 能力 | 具体能做的事 |
| --- | --- |
| 读书架与进度 | 「最近在读哪本、读到第几章、读完百分之几」、读过多少本 |
| 改书架 | 加书、删书（`shelf:write`） |
| 联网 | 抓网页文本、抓图片（走宿主直连，图片带磁盘缓存） |
| 往界面挂内容 | 6 个固定位置：我的（顶部/底部）、发现页（顶部/底部）、详情页底部、书城顶部 |
| 注册命令 | 出现在 `Ctrl+K` 命令面板，可带提示文字 |
| 订阅事件 | `app:ready`、`view:change`、`book:open` |
| 自己的存储 | 按插件隔离的 key-value（localStorage 命名空间） |
| 控制界面 | 切视图、打开某本书、打开书源管理、弹 toast、刷新自己挂的卡片 |

**不能做**（v1 明确不开放）：

- 不能用 `eval` / `new Function` / 内联脚本 —— 这条是**真拦住**的（CSP 没有 `unsafe-eval`，实测直接抛 CSP 错误）
- 没有「插件专用」的文件读写、进程、窗口 API（api 里没有这些）

**安全模型（务必理解，别指望权限当边界）**：插件与主程序**同源、同页面执行**，所以 `api.*` 只是「设计好的正规入口」，不是隔离墙。实测一个**声明零权限**的插件仍然可以：

- 直接读 `window.NR`（40 个模块）→ 读书架索引、读书源列表、读写主程序数据
- 直接调 `window.yedu`（宿主桥）→ 例如 `yedu.info()` 能拿到版本与数据目录
- 直接调 `NR.legado.fetchPage(...)` 抓任意网页（绕过 `api.net` 的 `net` 权限）
- 直接改 DOM（改 `document.title`、改 `#mainNav` 的样式）
- 直接读写 `localStorage`

也就是说：**manifest 的 `permissions` 只拦「误用正规入口」，拦不住任何想绕的人**。装第三方插件 = 把书架数据、联网能力、界面控制权全部交给对方。只装你信任的插件；我们不审计插件代码。

## 2. 目录与文件结构

插件是一个目录，目录名 = 插件 id：

```
plugins/
  hello/
    manifest.json      必需，元信息 + 权限声明
    main.js            必需（入口文件名由 manifest.entry 指定）
```

两个放置位置：

| 类型 | 路径 | 说明 |
| --- | --- | --- |
| 内置插件 | `<程序目录>\wwwroot\plugins\<id>\` | 由使用方自行放入，默认**启用**；本仓库与安装包均不含实现 |
| 用户插件 | `%LOCALAPPDATA%\iread-plugin-data\plugins\<id>\` | 使用者自装，默认**停用**，需在「我的 → 插件」中启用 |

「我的 → 插件」页面会显示用户插件目录的完整路径，并提供「打开插件目录」「重新加载」两个按钮。

> 放进新插件或改了代码后，必须点一次「重新加载」——插件脚本不会热更新。

## 3. manifest.json 字段

```json
{
  "id": "readboard",
  "name": "阅读看板",
  "version": "1.0.0",
  "author": "iread 示例",
  "description": "在「我的」顶部显示累计阅读时长、读过多少本与最近在读进度。",
  "permissions": ["shelf:read", "ui", "store", "commands"],
  "slots": ["mine.top"],
  "entry": "main.js"
}
```

| 字段 | 必需 | 类型 | 说明 |
| --- | --- | --- | --- |
| `id` | ✅ | string | **必须与目录名完全一致**，不一致会被拒绝加载 |
| `name` | ✅ | string | 显示名，管理面板里加粗显示 |
| `version` | ✅ | string | 显示为 `v1.0.0`，插件里通过 `api.version` 读到 |
| `permissions` | ✅ | string[] | 权限清单，见第 4 节；**不声明就拿不到对应 API** |
| `entry` | 否 | string | 入口脚本，默认 `main.js`；不要写前导 `/` |
| `slots` | 否 | string[] | 声明用到的插槽，只用于管理面板展示「显示位置」 |
| `description` | 否 | string | 管理面板里的说明 |
| `author` | 否 | string | 管理面板里的作者行 |

manifest 解析失败会在管理面板显示「manifest.json 不是合法 JSON」或「manifest.id 必须与目录名一致」。

## 4. 权限清单

> **v2 起权限不再拦截调用**：所有能力默认开放，`permissions` 只用来在管理面板里告诉用户「这个插件说它会用到什么」，同时「实际用到」那一栏会自动记录插件真正调了哪些能力。你仍然应该如实声明，方便用户判断来源是否可信。

| 权限 | 对应的能力（声明即可，不声明也能调） |
| --- | --- |
| `shelf:read` | `api.shelf.list/get/progress`、`api.stats.summary` |
| `shelf:write` | `api.shelf.add/remove` |
| `net` | `api.net.fetchText/fetchImage` |
| `ui` | `api.ui.mount/toast/row/form` |
| `commands` | `api.commands.register` |
| `events` | `api.events.on` |
| `store` | `api.store.get/set/del/keys`（每插件上限 512KB） |
| `fs` | `api.fs.*`（插件自己的数据目录） |
| `reader` | `reader.top` / `reader.bottom` 两个阅读页插槽 |
| `shortcuts` | `api.shortcuts.bind` |
| `theme` | `api.theme.current/on` |

## 5. 插槽（能挂内容的位置）

| 插槽 id | 位置 | 容器选择器 |
| --- | --- | --- |
| `mine.top` | 「我的」页，阅读统计卡下面 | `[data-plg-slot="mine.top"]` |
| `mine.bottom` | 「我的」页，设置行列表下面 | `[data-plg-slot="mine.bottom"]` |
| `discover.top` | 发现页顶部（热榜/历史之上） | `[data-plg-slot="discover.top"]` |
| `discover.bottom` | 发现页底部 | `[data-plg-slot="discover.bottom"]` |
| `detail.bottom` | 书籍详情页底部（跟着详情内容滚动） | `[data-plg-slot="detail.bottom"]` |
| `bookstore.top` | 书城顶部（书源栏之上） | `[data-plg-slot="bookstore.top"]` |
| `reader.top` | 阅读页顶部（章节标题之下） | `[data-plg-slot="reader.top"]` |
| `reader.bottom` | 阅读页底部（翻页栏之上） | `[data-plg-slot="reader.bottom"]` |

每个 `mount` 会拿到一个**新建的 `section.plg-card`** 作为 `box`，你往里写 HTML 即可。不要在 `box` 外操作 DOM。阅读页的两个插槽不套卡片底色（`plg-slot--reader`），样式上更像页眉/页脚，宽度跟随阅读区。

## 6. API 参考

插件入口固定写法：

```js
LampPlugin.define({
  setup: function (api) {
    // api.id / api.version / api.permissions / api.log(...)
    // 在这里调 api.* 注册插槽与命令
  }
});
```

`setup` 可以返回 Promise（运行时不等它，但会接住异常）。运行时会先把插件脚本加载完、再调用 `setup`，所以 `setup` 里可以随时调用其它 API。

### 6.1 基础

```js
api.id            // "readboard"
api.version       // "1.0.0"（manifest 里的 version，字符串）
api.permissions   // ["shelf:read","ui",...]（副本，改它没用）
api.log('ok', 1)  // 输出 "[plugin:readboard] ok 1"
```

### 6.2 api.shelf（需要 `shelf:read` / `shelf:write`）

```js
api.shelf.list()                 // → Promise<Array<书架条目>>
api.shelf.get(id)                // → Promise<条目 | null>
api.shelf.progress(id)           // → Promise<{ ci, ratio, percent, total }>
api.shelf.add({ title, author, bookUrl, sourceId })   // 需要 shelf:write
api.shelf.remove(id)             // 需要 shelf:write
```

书架条目就是主程序 `nr_index` 里的对象，常用字段：`id`、`title`、`author`、`sourceId`、`chapterCount`、`chapterTitles`、`progress: { ci, ratio }`、`lastReadAt`、`addedAt`。

进度换算（与阅读看板示例一致）：

```js
var total = book.chapterCount || (book.chapterTitles || []).length || 0;
var p = book.progress || { ci: 0, ratio: 0 };
var percent = total > 0 ? Math.round(((p.ci || 0) + (p.ratio || 0)) / total * 100) : 0;
```

### 6.3 api.stats（需要 `shelf:read`）

```js
api.stats.summary()   // → { totalMs, readCount }（同步返回，无数据时 totalMs:0 readCount:0）
```

### 6.4 api.net（需要 `net`）

```js
api.net.fetchText('https://example.com/list')          // → Promise<string>
api.net.fetchImage('https://example.com/a.jpg')        // → Promise<data:image/...;base64,...>
api.net.fetchText(url, { timeout: 15000 })             // 可选参数
```

`fetchImage` 走宿主的磁盘封面缓存（命中就直接返回，不联网），可以直接塞进 `<img src>`。

### 6.5 api.ui（需要 `ui`）

```js
api.ui.mount('mine.top', function (box) {
  box.innerHTML = '<div class="plg-card__head"><b>标题</b></div>';
});
api.ui.toast('已保存');
api.ui.refresh();     // 重画自己挂过的所有插槽
```

`render(box)` 可以返回 Promise；抛错或 reject 时该卡片会显示「插件出错：…」，不影响主程序。

推荐用内置样式类，能自动跟随九套主题：

| 类名 | 用途 |
| --- | --- |
| `.plg-card__head` | 卡片标题行（里面放 `<b>` 加 `.plg-card__sub`） |
| `.plg-kv` / `.plg-kv__cell` / `.plg-kv__k` / `.plg-kv__v` | 三格数据块 |
| `.plg-line` | 一行说明文字 |
| `.plg-bar`（内含 `<i style="width:40%">`） | 进度条 |
| `.plg-card__err` | 错误文字 |

#### 插件页面的返回键（`onBack`）

插件页面是独立视图（`plg:<插件id>:<页面id>`），安卓系统返回键 / 桌面 Esc 会先问插件自己：

```js
api.ui.page({
  id: 'main',
  title: '我的插件',
  render: function (box) { /* 画界面 */ },
  onBack: function () {
    if (view === 'detail') { view = 'home'; render(); return true; }  // 退了一层
    return false;                                                    // 已在本插件最上级
  }
});
```

- 返回 `true`：插件自己退了一层（详情 → 列表、看图 → 详情…），应用不退出。
- 返回 `false`（或没写 `onBack`）：说明已经在插件最上级，宿主会**直接退出应用**，
  与主界面「书架/发现/书城/我的 最上级按返回就是退出」的规矩一致。
- 插件内也可以主动问：`NR.plugins.back()`、`NR.plugins.currentPage()`（返回当前页面 key，非插件页返回空串）。

### 6.6 api.commands（需要 `commands`）

```js
api.commands.register({
  id: 'refresh',                 // 运行时自动命名空间化成 "readboard:refresh"
  label: '刷新阅读看板',
  hint: '重算统计',               // 可选
  run: function () { api.ui.refresh(); }   // 可返回 Promise
});
```

用户按 `Ctrl+K`（或 `Ctrl+Shift+P`）打开命令面板，输入关键字执行。

### 6.7 api.events（需要 `events`）

```js
api.events.on('app:ready', function () {});
api.events.on('view:change', function (e) { /* e.view: online|bookstore|shelf|mine|read */ });
api.events.on('book:open', function (e) { /* e: { id, title, sourceId } */ });
```

### 6.8 api.store（需要 `store`）

```js
api.store.get('lastRender', 0)   // 取不到时返回第二个参数（缺省 null）
api.store.set('lastRender', Date.now())
api.store.del('lastRender')
api.store.keys()                 // → ['lastRender']
```

存储按插件隔离（实际 key 前缀 `plg:<插件id>:`），值走 JSON 序列化。

### 6.9 api.app

```js
api.app.version()        // → "1.0.0-plugin.1"
api.app.view()           // → 'mine'
api.app.switchView('mine')
api.app.openBook(id)     // → Promise
api.app.openSources()    // 打开书源管理抽屉
```

## 7. 完整示例（阅读看板）

约 80 行，三件事：读取书架与统计数据、往 `mine.top` 挂卡片、注册一个命令。

```js
LampPlugin.define({
  setup: function (api) {
    function render(box) {
      box.innerHTML = '<div class="plg-card__head"><b>阅读看板</b>' +
        '<span class="plg-card__sub">示例插件 · v' + api.version + '</span></div>' +
        '<p class="plg-line">正在读取…</p>';

      return Promise.all([api.shelf.list(), Promise.resolve(api.stats.summary())])
        .then(function (res) {
          var books = res[0] || [], stats = res[1] || {};
          var recent = null;
          books.forEach(function (b) {
            if (!b) return;
            if (!recent) { recent = b; return; }
            if ((b.lastReadAt || b.addedAt || 0) > (recent.lastReadAt || recent.addedAt || 0)) recent = b;
          });

          var html = '<div class="plg-card__head"><b>阅读看板</b></div>' +
            '<div class="plg-kv">' +
            '<div class="plg-kv__cell"><span class="plg-kv__k">累计阅读</span>' +
            '<span class="plg-kv__v">' + (stats.totalMs / 3600000).toFixed(2) + ' <small>小时</small></span></div>' +
            '<div class="plg-kv__cell"><span class="plg-kv__k">读过</span>' +
            '<span class="plg-kv__v">' + (stats.readCount || 0) + ' <small>本</small></span></div>' +
            '<div class="plg-kv__cell"><span class="plg-kv__k">在架</span>' +
            '<span class="plg-kv__v">' + books.length + ' <small>本</small></span></div>' +
            '</div>';

          if (recent) {
            var total = recent.chapterCount || (recent.chapterTitles || []).length || 0;
            var p = recent.progress || { ci: 0, ratio: 0 };
            var percent = total > 0 ? Math.min(100, Math.round(((p.ci || 0) + (p.ratio || 0)) / total * 100)) : 0;
            html += '<p class="plg-line">最近在读：' + recent.title + ' · 第 ' + (p.ci + 1) + ' / ' + total + ' 章 · ' + percent + '%</p>' +
                    '<div class="plg-bar"><i style="width:' + percent + '%"></i></div>';
          } else {
            html += '<p class="plg-line">书架还是空的，先加一本书吧。</p>';
          }

          box.innerHTML = html;
          try { api.store.set('lastRender', Date.now()); } catch (e) {}
        });
    }

    api.ui.mount('mine.top', render);
    api.commands.register({
      id: 'refresh', label: '刷新阅读看板', hint: '重算统计',
      run: function () { api.ui.refresh(); api.ui.toast('阅读看板已刷新'); }
    });
  }
});
```

要点：
- `render` 每次被调用都要**重画整块**（运行时会先清空 `box`）；异步用 Promise 返回，别用 `await` 顶层（脚本按经典脚本加载，不用 ES module）。
- 用户插入字符串一定要转义（示例里用 `esc()`），否则书名里的 `<` 会破坏结构。
- 数据变了（比如读完一章）主动 `api.ui.refresh()`，否则界面不会自动更新。

## 8. 调试与打包

**看日志**：`api.log(...)` → 控制台。开发时可以用调试端口启动：

```
iread-plugin.exe %TEMP%\r.json iread --data-dir=%TEMP%\plg-dev --devtools-port=9222
```

再连 `http://127.0.0.1:9222` 打开 DevTools 看 Console（生产环境默认不开端口）。

**常见的加载失败原因**（管理面板卡片会写出来）：

| 提示 | 原因 |
| --- | --- |
| `manifest.json 不是合法 JSON` | 多了逗号、用了单引号、BOM 之外的编码问题 |
| `manifest.id 必须与目录名一致` | 目录 `Hello`、id `hello` 大小写不一致 |
| `插件脚本加载失败：https://plugins.local/...` | `entry` 文件名写错、文件不在目录根 |
| `插件没有调用 LampPlugin.define` | 入口脚本忘了调用或调用了两次 |
| `插件「x」没有声明权限 y` | manifest `permissions` 少了 |

**改完代码**：点「我的 → 插件 → 重新加载」。

**分发**：把整个插件目录（`manifest.json` + `main.js` + 其它资源）压缩发给对方，解压进
`%LOCALAPPDATA%\iread-plugin-data\plugins\` 即可；提醒对方「权限只拦误用，装之前确认来源」。

**做成内置插件**：本仓库不随附插件源码。分发方式只有两种——目录拷贝或 zip 导入。

## 9. 边界与后续

已知边界（v2）：

- 同源执行，**无沙箱**；`permissions` 从 v2 起**不再拦截**，只作展示与「实际用到」记录（见第 1 节实测清单）
- 唯一硬拦截是 CSP：`eval`/`new Function`/内联脚本会被浏览器拒绝
- 插件状态**不进备份**（启用状态在 localStorage，不写 IndexedDB）
- 插件之间没有依赖/加载顺序保证（按「内置优先、同名按名称排序」）
- `setup()` 有 **3 秒超时**：卡住会被跳过并在管理面板报错，不会拖死其它插件
- 每个插件的 `api.store` 上限 **512KB**；大块数据请用 `api.fs` 写文件
- 宿主命令桥 `yedu` 没有为插件做任何过滤，插件可以调用它暴露的全部命令

后续可做（按需再排期）：插件专属设置页（现在用 `api.ui.form` 弹窗代替）、插件依赖与版本约束、插件市场、崩溃隔离（独立 worker）。

## 10. v2 新增能力（2026-11-04）

### 10.1 文件读写 `api.fs`（权限名 `fs`）

插件有自己的数据目录（`<数据根>\plugin-data\<插件id>\`），可以直接读写文件、做缓存、存书架之外的资料。

```js
await api.fs.dir();                        // → 目录绝对路径
await api.fs.write('cache/a.txt', 'hi');   // 覆盖写；子目录会自动建
await api.fs.append('log.txt', 'line\n');
await api.fs.read('cache/a.txt');          // → 字符串（不存在时抛错）
await api.fs.list();                       // → [{ name, size, dir, mtime }]
await api.fs.remove('log.txt');            // 文件或目录
```

路径里的 `..`、`/`、`\`、`:` 会被拒绝，只能在自己的目录里活动。

### 10.2 设置表单 `api.ui.form`

不用自己画界面，弹一个原生风格的设置框，用户点「保存」后拿到值：

```js
var v = await api.ui.form({
  title: '阅读看板设置',
  desc: '这些值会存进 api.store 的 settings 键',
  fields: [
    { key: 'nick', label: '昵称', type: 'text', value: '书友', hint: '显示在看板上' },
    { key: 'rows', label: '每页行数', type: 'number', min: 5, max: 50, value: 10 },
    { key: 'auto', label: '打开就刷新', type: 'switch', value: true },
    { key: 'theme', label: '配色', type: 'select', options: [{ value: 'a', label: 'A' }], value: 'a' },
    { key: 'memo', label: '备注', type: 'textarea', rows: 3 }
  ]
});
if (v) { /* v = {nick:'书友', rows:10, auto:true, ...}，同时已写进 api.store 'settings' */ }
// 用户点取消 → null
```

### 10.3 快捷键 `api.shortcuts.bind(combo, fn)`

```js
api.shortcuts.bind('Ctrl+Alt+K', function () { api.ui.toast('你按了快捷键'); });
```

组合键支持 `Ctrl/Cmd/Alt/Shift` + 字母/数字/F1–F12/方向键等；冲突时**先注册的先赢**。插件注册的快捷键优先于主程序（`Ctrl+K` 命令面板）。

### 10.4 主题联动 `api.theme.current()` / `api.theme.on(fn)`

```js
var t = api.theme.current();
// { name:'ink', dark:true, bg:'#0a0b0d', panel:'#0e1013', fg:'#ffffff',
```

## 十一、视频播放页（`NR.video`，v1.0.0-plugin.1 起）

视频不再借用阅读器，而是进一个独立的播放页。插件只要把「线路 + 剧集」交给它就行：

```js
NR.video.open({
  title: '片名',
  intro: '简介（可选）',
  cover: 'https://…/poster.jpg',      // 播放前的海报
  sourceName: '量子',
  bookUrl: 'https://…/detail/123',    // 续播的唯一键，建议用详情页地址
  lines: [                             // 多线路：一条线路一组剧集
    { from: 'lzm3u8', eps: [{ t: '第01集', url: 'https://…/index.m3u8' }] },
    { from: 'hnm3u8', eps: [{ t: '第01集', url: 'https://…/index.m3u8' }] }
  ],
  lineIdx: 0,        // 默认线路
  index: 0,          // 默认集（0 起）
  headers: { Referer: 'https://站点/' },  // 可选：交给宿主在 WebResourceRequested 注入
  from: 'plg:cmstv:main'                  // 返回时回到哪个页面
});
```

- 只接受 **直出视频流**（`.m3u8` / `.mp4`）的地址；播放页线路（要解析接口的）会在面板里灰显「需解析」
- 播放能力：hls.js（m3u8）/ 原生（mp4）、断点续播（localStorage `nr_vresume`，按 `bookUrl` 记线路+集+秒）、自动下一集（5 秒倒计时可取消）、倍速、画中画、全屏
- 快捷键：`空格/K` 播放暂停、`←/→` ±10s（`Shift` ±60s）、`↑/↓` 音量、`M` 静音、`F` 全屏、`N` 下一集、`C` 选集、`Esc` 返回
- 其它接口：`NR.video.close()`、`NR.video.state()`（探针用）、`NR.video.keyOf(opts)`、`NR.video.resumeOf(key)`、`NR.video.clearResume(key)`
